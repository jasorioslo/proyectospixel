Generar Lista de Números

Crea una lista de números correlativos definiendo inicio, fin y paso.

Qué hace el generador de listas de números

Crea una lista de números correlativos definiendo desde, hasta y paso, con separador configurable (salto de línea, coma, espacio o guion).

También funciona en orden inverso: si el valor inicial es mayor que el final, la lista baja. Con límite de seguridad de 100.000 números.

Cómo generar una lista de números paso a paso

  1. Define los valores: desde (1), hasta (10) y paso (1).
  2. Elige el separador que necesites (líneas, comas, espacios, guiones).
  3. Pulsa generar y copia la lista completa.

Casos de uso

  • Rellenar formularios y plantillas con series.
  • IDs y numeraciones para pruebas.
  • Inventarios, dorsales, entradas correlativas.
  • Datos para gráficas o simulaciones.

Ejemplos

  • desde 1, hasta 5, paso 1 → 1\n2\n3\n4\n5

Preguntas frecuentes

¿Puedo usar decimales o pasos grandes?

El paso es un entero mayor que 0; para pasos de miles (100, 200, 300) también funciona.

¿Y en orden descendente?

Sí: pon un «desde» mayor que el «hasta» y la lista baja.

¿Hay límite?

Hasta 100.000 números por lista para no bloquear el navegador.

¿Se guarda mi lista?

No, se genera localmente.

Herramientas relacionadas
