Combinar Líneas de Dos Listas

Genera todas las cruces posibles de la lista A con la lista B.

Qué es el producto cruzado de dos listas

Genera todas las combinaciones cruzadas entre la lista A y la lista B: cada elemento de A con cada elemento de B (A × B).

Es la misma mecánica que usarías para crear variantes de keywords (servicio × ciudad) o todas las opciones de un producto.

Cómo combinar dos listas paso a paso

  1. Pega la lista A (por ejemplo, servicios) y la lista B (ciudades).
  2. Elige el separador y si quieres invertir el orden (B primero).
  3. Pulsa combinar: obtendrás todas las cruces (A×B) con el total indicado.

Casos de uso

  • Keyword research: combina servicio + ciudad para SEO local.
  • E-commerce: variantes de color × talla.
  • Campañas: títulos de anuncio por audiencia × beneficio.
  • Inventarios de referencia únicas.

Ejemplos

  • A: barato/rápido · B: zapatos/camisas → barato zapatos, barato camisas, rápido zapatos, rápido camisas

Preguntas frecuentes

¿Cuál es el límite?

10.000 combinaciones cruzadas por consulta.

¿Puedo poner la B primero?

Sí, con la opción «invertir orden» (el resultado cambia de orden, no de contenido).

¿Se guardan mis listas?

No, el cruce se calcula en tu navegador.

¿Diferencia con fusionar listas?

Fusionar une por índice (a1 con b1); combinar genera todas las cruces posibles.
