Generador de Permutaciones

Todas las permutaciones posibles de los elementos de tu lista.

El número de permutaciones crece como n! (8 elementos = 40.320). Se recomienda trabajar con 6 o menos.

Qué son las permutaciones (n!)

Las permutaciones son todas las formas de ordenar un conjunto: con «uno, dos» salen «uno dos» y «dos uno». El número de ordenaciones es el factorial de n (n!), que crece rápido: 3! = 6, 5! = 120, 8! = 40.320.

Aquí generas todas las permutaciones de tu lista (hasta 8 elementos) con orden aleatorio garantizado por el algoritmo de Heap.

Cómo generar permutaciones paso a paso

  1. Pega los elementos, uno por línea (máximo 8; los duplicados se quitan automáticamente).
  2. Elige el separador entre elementos.
  3. Pulsa generar: verás el total (n!) y todas las ordenaciones.

Casos de uso

  • Planificación de rutas: todos los órdenes de visita posibles.
  • Tests combinatorios: ordenaciones para probar un sistema.
  • Juegos y puzles: todos los arreglos de unas piezas.
  • Docencia: ver crecer el factorial.

Ejemplos

  • uno, dos → uno dos · dos uno

Preguntas frecuentes

¿Por qué el límite de 8 elementos?

Porque 8! = 40.320 y 9! ya son 362.880: bloquearían el navegador. Para más casos, usa combinaciones o filtra antes.

¿Se eliminan los duplicados?

Sí: elementos repetidos no generan permutaciones duplicadas.

¿Se guardan mis datos?

No, las ordenaciones se generan localmente.

¿Permutaciones o combinaciones?

Permutaciones = importa el orden (n!); combinaciones = no importa (C(n,k) y son menos).
