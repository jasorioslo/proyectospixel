Qué hace el contador de clics

Es un tally counter interactivo: pulsa «+1» para contar, «−1» para corregir y «Resetear» para empezar de cero. Incluye atajos de teclado (+ y −, flechas arriba/abajo, R para reiniciar) y un campo de ajuste manual.

Perfecto para contar personas, repeticiones de un ejercicio, objetos en movimiento o cualquier cosa que requiera contar con el dedo.

Cómo usar el contador de clics paso a paso

  1. Pulsa «+1 Contar» (o la tecla +) para incrementar el contador.
  2. Corrige con «−1» (o −) si te equivocas; también puedes escribir un valor exacto en «ajuste manual».
  3. Pulsa «Resetear» (o R) para volver a cero.

Casos de uso

  • Deporte: contar series, repeticiones o vueltas.
  • Grupos y eventos: aforo manual, personas que entran.
  • Inventario rápido: contar objetos o cajas.
  • Hábitos: llevar la cuenta de repeticiones diarias.

Preguntas frecuentes

¿Funciona sin ratón?

Sí: usa las teclas + y -, las flechas arriba/abajo y la R para resetear.

¿Puedo fijar un valor concreto?

Sí, con el campo de ajuste manual (acepta números negativos también).

¿Se guarda el conteo si recargo?

No: es en memoria. Apunta el número final antes de recargar.

¿Se envía algo?

No, todo es local.
