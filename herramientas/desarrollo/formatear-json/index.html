Formatear y Validar JSON

Embellece tu JSON, valídalo al instante (con línea y columna del error) y ordénalo alfabéticamente si quieres.

Qué hace el formateador de JSON

Embellece un JSON en un clic (indentación 2/4 espacios o tabulación), lo valida al instante indicando línea y columna del error y permite ordenar las claves alfabéticamente.

El compañero ideal para depurar una API o revisar configuraciones sin instalar nada.

Cómo formatear y validar un JSON paso a paso

  1. Pega el JSON (minificado o no).
  2. Pulsa «Formatear JSON»: si hay un error, lo indica con línea, columna y el motivo exacto.
  3. Copia el resultado ya indentado; si quieres, activa «ordenar claves» antes de formatear.

Casos de uso

  • Depurar APIs: lee respuestas minificadas.
  • Configuraciones: valida un package.json o un archivo de ajustes.
  • Comparar: formatea dos JSON y usa el comparador de textos.
  • Enseñar ejemplos legibles en documentación.

Preguntas frecuentes

¿Detecta dónde está el error?

Sí: muestra el mensaje nativo, la línea y la columna del fallo (y valida mientras escribes).

¿Puede ordenar las claves?

Sí, activa la opción y las claves se ordenan alfabéticamente, de forma recursiva.

¿Soporta JSON grandes?

Sí, sin límite práctico más allá de la memoria de tu navegador.

¿Se envía mi JSON?

No: la validación es local. Nada sale de tu dispositivo.
