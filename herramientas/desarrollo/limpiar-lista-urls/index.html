Limpiar Lista de URLs

Deja solo el dominio raíz de cada URL: quita http, rutas y parámetros.

Qué hace el limpiador de listas de URLs

Convierte una lista de direcciones en una lista limpia de dominios raíz: quita protocolo, «www», rutas y parámetros, y elimina duplicados automáticamente.

Ideal para SEO técnico y análisis: saber de qué dominios tienes enlaces, consolidar menciones o preparar disavow.

Cómo limpiar una lista de URLs paso a paso

  1. Pega las URLs, una por línea.
  2. Elige el modo: solo dominio (sin www ni rutas), dominio con www, o URL raíz con https://.
  3. Pulsa limpiar y copia el resultado (sin duplicados).

Casos de uso

  • Auditoría de enlaces: lista limpia de dominios que te enlazan.
  • Menciones de marca: consolida todas las apariciones de cada sitio.
  • Investigación de competencia: deduplica sus fuentes de backlinks.
  • Listas de contacto web: extrae el dominio de una lista de webs.

Ejemplos

  • https://www.ejemplo.com/ruta?x=1 → ejemplo.com

Preguntas frecuentes

¿Quita los duplicados?

Sí, por defecto. Si el mismo dominio aparece varias veces, se conserva una sola línea.

¿Y los subdominios?

Se normalizan quitando «www»; otros subdominios se conservan como parte del dominio.

¿Valida las URLs?

Sí: descarta las que no son direcciones válidas.

¿Se guardan mis datos?

No: el análisis es local en tu navegador.
