Cifrador César de Texto

Desplaza cada letra N posiciones del abecedario. Usa el mismo N para cifrar y descifrar al revés.

Qué es el cifrado César

El cifrado César es el abuelo de los cifrados: desplaza cada letra N posiciones (Julio César usaba 3). Con ROT13 el desplazamiento es 13 y no se puede elegir; aquí tú decides el desplazamiento (1-25).

Útil para ejercicios de criptografía, juegos y mensajes informales. No lo uses para información sensible: se rompe por fuerza bruta en segundos.

Cómo cifrar con César paso a paso

  1. Pega el texto.
  2. Elige acción (cifrar o descifrar) y el desplazamiento entre 1 y 25.
  3. Pulsa aplicar y copia el resultado (para descifrar, usa el mismo desplazamiento).

Casos de uso

  • Clases de criptografía y talleres.
  • Juegos de espías y escape rooms.
  • Retos de ingenio: cifra con un desplazamiento y que lo adivinen.
  • Mensajes informales para que no se lean de reojo.

Ejemplos

  • abc con desplazamiento 3 → def

Preguntas frecuentes

¿Cómo descifro un mensaje?

Selecciona «Descifrar» y usa el mismo desplazamiento con el que se cifró.

¿Por qué no acepta 26?

Porque 26 equivale a cero: la letra no cambia. El rango útil es 1-25.

¿Respeta mayúsculas y símbolos?

Sí: las mayúsculas se mantienen y los signos o números no se modifican.

¿Se envía mi texto?

No, la operación es local.
