Comparar Hash y Texto

Comprueba si el hash calculado de un texto coincide con el hash esperado.

Qué hace el comparador de hash y texto

Comprueba si un hash (MD5, SHA-1, SHA-256, SHA-384 o SHA-512) corresponde a un texto concreto: pega el texto y el hash esperado y la herramienta recalcula y compara (detecta solo el algoritmo por la longitud del hash).

Es la forma rápida de verificar integridad sin descargar utilidades: «¿este archivo es el original?», «¿este hash es de mi contraseña?».

Cómo comprobar un hash paso a paso

  1. Pega el texto original en el primer campo.
  2. Pega el hash que quieres verificar (la herramienta detecta el algoritmo por su longitud).
  3. Pulsa comprobar: verás «COINCIDE» o «NO COINCIDE» junto a ambos valores.

Casos de uso

  • Verificar descargas: compara el hash publicado con el de tu archivo (usando el texto correspondiente).
  • Depurar: comprobar si un hash almacenado viene del texto esperado.
  • Testing: validar que tu función de hash devuelve el valor correcto.
  • Aprender: comprobar que a un texto le corresponde exactamente ese hash.

Ejemplos

  • md5(abc) = 900150983cd24fb0d6963f7d28e17f72 → COINCIDE

Preguntas frecuentes

¿Cómo sabe el algoritmo?

Por la longitud: 32 hex = MD5, 40 = SHA-1, 64 = SHA-256, 96 = SHA-384 y 128 = SHA-512. También puedes elegirlo a mano.

¿Distingue mayúsculas en el hash?

No: la comparación es insensible a mayúsculas/minúsculas en el hash.

¿Se envía mi texto?

No: la comprobación es local.

¿Puedo usarlo para «descifrar» un hash?

No: solo compara. Si tienes el texto candidato, verifica si produce ese hash.

Herramientas relacionadas

Complétala con Generador de hashes, Generador de HMAC o Verificador de contraseñas.
