Conversión de Formatos de Texto

Convierte cualquier texto entre formatos: Morse, Base64, Unicode y binario UTF-8, al instante y sin salir de tu navegador.

Qué son las herramientas de conversión online

Transforman un formato en otro: texto a Morse y a binario, Base64, escapes Unicode, JSON a CSV, Markdown a HTML e imágenes a PDF. Son la navaja suiza para mover datos entre sistemas y lenguajes.

Todas funcionan en tu navegador: útil cuando conviertes datos internos, configuraciones o documentos y prefieres no subirlos a un servicio de terceros.

Cómo convertir datos paso a paso

  1. Elige la conversión: ¿texto↔Morse, texto↔Base64, JSON↔CSV, Markdown→HTML o imágenes→PDF?
  2. Pega o sube el contenido de origen. Varias son reversibles (Base64, Morse, binario, JSON/CSV).
  3. Configura las opciones (sentido de la conversión, delimitador, tamaño de página…) y pulsa convertir.
  4. Copia o descarga el resultado ya en el formato de destino.

Conversiones reversibles y con validación

Muchas de estas herramientas funcionan en ambos sentidos y validan la entrada: si el Base64 o el Morse no son válidos, te avisan indicando el carácter o byte exacto del problema. Así detectas errores en lugar de obtener resultados silenciosamente mal.

Casos de uso

  • Desarrollo: codificar Base64, convertir JSON a CSV, procesar escapes Unicode.
  • Documentación: pasar Markdown a HTML para una web o un CMS.
  • Trámites: unir fotos en un PDF para subirlo donde solo aceptan ese formato.
  • Educación y juegos: Morse y binario para mensajes en clave.

Ejemplos rápidos

  • hola → aG9sYQ== (Base64)
  • SOS → ... --- ... (Morse)
  • Ho → 01001000 01101111 (binario UTF-8)

Preguntas frecuentes

¿Base64 cifra el texto?

No: lo codifica, no lo cifra. Cualquiera puede decodificarlo. Para proteger datos usa las herramientas de cifrado.

¿Las conversiones son reversibles?

La mayoría sí (Base64, Morse, binario, Unicode, JSON↔CSV). Markdown→HTML e imágenes→PDF van en un solo sentido.

¿Con acentos, ñ o emojis?

Sí: se trabaja en UTF-8, por lo que los caracteres no ASCII se conservan.

¿Se suben mis archivos o datos?

No: todo se procesa localmente. En imágenes a PDF, por ejemplo, el PDF se genera en tu equipo.

¿Cuál uso para íconos o charsets?

Para escapar caracteres especiales en código usa Unicode; para transporte de datos, Base64.
