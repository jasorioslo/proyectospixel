Codificar/Decodificar Base64

Convierte cualquier texto a Base64 o descifra Base64 a texto plano.

Qué es Base64 y para qué se usa

Base64 es una codificación que representa datos binarios o texto usando 64 caracteres seguros (letras, números, + y /). Sirve para transportar datos en entornos que solo aceptan texto: correos, URLs, JSON, tokens.

Con esta herramienta codificas cualquier texto a Base64 o descifras Base64 a texto legible, con validación y aviso si la cadena no es válida.

Cómo codificar y decodificar Base64 paso a paso

  1. Pega el texto (o la cadena Base64).
  2. Elige la acción: codificar (texto → Base64) o decodificar (Base64 → texto).
  3. Pulsa el botón y copia el resultado. Si el Base64 es inválido, verás el error.

Casos de uso

  • APIs y cabeceras: enviar credenciales o datos binarios como texto.
  • Tokens y JWT: entender sus partes codificadas.
  • Datos en JSON/XML: incrustar contenido seguro sin caracteres raros.
  • Aprendizaje: ver qué hay detrás de una cadena Base64.

Ejemplos

  • hola → aG9sYQ==

Preguntas frecuentes

¿Base64 cifra el texto?

No: lo codifica, no lo cifra. Cualquiera puede decodificarlo. Para proteger datos usa cifrado (AES).

¿Con acentos y emojis?

Sí: se procesa en UTF-8, así que los caracteres no ASCII se conservan al decodificar.

¿Qué es el «=» del final?

El relleno (padding) para completar el último bloque; es normal y no es un error.

¿Se sube mi texto?

No: todo ocurre en tu navegador.
