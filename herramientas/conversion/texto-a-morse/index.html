Texto a Morse

Traduce texto a código Morse y de Morse a texto.

Qué hace el traductor a código Morse

Traduce texto a código Morse y también al revés (Morse a texto), con validación: si el código tiene símbolos desconocidos, te avisa indicando cuál.

Usa el alfabeto Morse internacional, con letras, números y puntuación básica.

Cómo traducir texto a Morse paso a paso

  1. Pega el texto (o el código Morse con puntos, rayas y espacios).
  2. Elige el sentido: texto → Morse o Morse → texto.
  3. Copia el resultado. Si el Morse no es válido, verás el símbolo exacto que falla.

Casos de uso

  • Historia y CTS: practicar radiocomunicaciones.
  • Juegos y escape rooms: crear mensajes en clave.
  • Actividad escolar y talleres de comunicación.
  • Retos y acertijos con mensajes ocultos.

Preguntas frecuentes

¿Separa las letras y las palabras?

Sí: un espacio entre letras y una barra «/» entre palabras, el estándar.

¿Soporta números y puntuación?

Sí, el alfabeto Morse internacional incluye números y signos básicos.

¿Y las tildes o la ñ?

Morse es un alfabeto limitado: se recomienda usar el generador de slugs o quitar acentos antes de traducir.

¿Funciona sin internet?

Sí, todo se procesa en tu navegador (PWA offline).
