Convertir Unicode/Texto

Codifica texto a formato Unicode o decodifica Unicode a texto legible.

Qué son las secuencias Unicode (\uXXXX)

En JavaScript y muchos lenguajes, los caracteres pueden escribirse como secuencias de escape Unicode: «á» es «\u00E1», «ñ» es «\u00F1». Esta herramienta convierte en ambos sentidos.

Útil para depurar datos, escribir cadenas seguras en código, mover texto entre sistemas o descifrar caracteres que aparecen como «\uXXXX» en un JSON.

Cómo convertir Unicode paso a paso

  1. Pega el texto (o las secuencias \uXXXX).
  2. Elige dirección: texto → Unicode (escapes) o Unicode → texto (legible).
  3. Copia el resultado; si una secuencia no es válida, la herramienta te avisa.

Casos de uso

  • Programación: escribir caracteres especiales con escapes seguros.
  • Depurar JSON/APIs donde el texto llega codificado.
  • Traducciones técnicas que usan \uXXXX de forma habitual.
  • Docencia: mostrar la diferencia entre carácter y código.

Ejemplos

  • ñ → \u00F1
  • \u00F1 → ñ

Preguntas frecuentes

¿Qué formato usa?

Escapes de 4 dígitos hexadecimales (\uXXXX), el estándar de JavaScript y JSON.

¿Soporta emojis (fuera del BMP)?

Los caracteres fuera del plano básico se expresan con pares de escapes; la herramienta avisa si el formato no es válido.

¿Se envía mi texto?

No: la conversión es local.

¿Diferencia con Base64?

Unicode deja el texto legible en código; Base64 lo transforma por completo para transporte de datos.
