Convertir JSON a CSV (y viceversa)

Pasa de JSON a CSV o de CSV a JSON con control de delimitador y cabeceras. Todo local.

Qué hace el conversor JSON ↔ CSV

Pasa de JSON a CSV (ideal para abrir datos en Excel o Google Sheets) y de CSV a JSON (para APIs y código), con delimitador configurable y cabeceras.

Maneja correctamente el entrecomillado CSV: valores con comas, comillas o saltos de línea se exportan seguros.

Cómo convertir JSON a CSV (y viceversa) paso a paso

  1. Elige la dirección: JSON → CSV o CSV → JSON.
  2. Pega los datos (array de objetos o filas con delimitador) y ajusta delimitador (coma, punto y coma, tabulador) y cabeceras.
  3. Pulsa convertir y copia el resultado.

Casos de uso

  • Análisis de datos: volcar una API JSON a una hoja de cálculo.
  • Importar/exportar a CRM, ERP o BI.
  • Preparar fixtures JSON a partir de una tabla CSV.
  • Limpieza previa: detectar claves irregulares (se unifican como columnas).

Ejemplos

  • [{"nombre":"Ana","edad":30}] → nombre,edad\nAna,30

Preguntas frecuentes

¿Qué pasa si los objetos tienen claves distintas?

Se calcula la unión de todas las claves: las filas sin ese campo quedan vacías.

¿Respeta las comas dentro de los valores?

Sí: valores con comas, comillas o saltos se entrecomillan correctamente según el estándar CSV.

¿Hay límite de filas?

Hasta 10.000 filas por conversión, para no bloquear el navegador.

¿Se suben mis datos?

No: la conversión es local.
